Space

Every record placed by what it is (kind, envelope state, owning run), not by what it links to. Proximity approximates pattern matchability: two records sitting together are two records one pattern would likely both match. Streamed live from the ops event log; layout is deterministic, so the same events always give the same picture. Scroll to zoom (levels aggregate into supernodes), drag to pan, click a record for detail, r/R for the compass and control panels.

Sign in as a person

Mint a session for a named human through the same bootstrap chain every agent uses (agent_definition → agent_run), the console's equivalent of radia login. Operator only: grants are assigned, never self-declared. Use it to see the space as someone else sees it, and to hand a person a credential of their own so identity-scoped grants can tell two people apart.

Authorization

The bootstrap chain, read straight from the substrate: agent_definition → its agent_runs (run tokens) → the grant records that scope each principal. All are ordinary records (only the token hash is stored). A definition is an agent: worker or a human: person; the namespace confers no privilege, so a person here holds exactly what was assigned. The chat example creates these on every run (deno task chat).
