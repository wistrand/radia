What this is: the same runtime the server binary runs (storage, matching, leases, the full authorization stack, the event chain), booted in this tab with the actual console embedded above. The page seeds one claimable kind, document, and one toy worker that claims scans and answers with a summary record. The console starts at its sign-in screen because it never assumes authority silently: this space runs in open mode, so the operator session is a labeled button rather than a default, in the browser exactly as on a server.

The jail above is a Web Worker inside a sandboxed iframe: an opaque origin, so it cannot open this space's database, and a policy of connect-src 'none', so it has no network. Those two claims are attempted before the button appears, and a browser where either fails is not offered one. The code holds no credential at all; it proposes reads and writes, and this page performs each one under the agent's identity.

If you have the browser console open, the probe leaves its evidence there: a Content-Security-Policy message saying a connect-src request to this page's own address was refused. That is the jail's network wall turning away a request the probe made ON PURPOSE, and the reason the verdict above can say network: false rather than assuming it. A run that produced no such message would be the worrying one.

Which is why the snippet can still be useful: it queries the summaries the worker produced, rolls them into a report, and names those summaries as its parents. The host adds the record it was run for on top, so the report's lineage is honest whether or not the code cooperated. Open Graph: last record after running it and the fan-in is the picture: documents to summaries to one report.

Limits, stated rather than implied: no processes (so no Python and no multi-file workspace trees yet, only JavaScript snippets), memory is the one axis a browser cannot cap, one space per browser profile, and everything here runs as one person, so the console's operator button is the sign-in. Erasing the space is clearing this site's storage.
