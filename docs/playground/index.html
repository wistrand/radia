A space in this tab

This page boots the same runtime the server binary runs: Postgres compiled to WASM for storage (persisted in this browser via IndexedDB), the full authorization stack, the event chain, and the actual console, embedded below. Nothing is installed and nothing leaves the tab. The page seeds one claimable kind, document, and one toy worker that claims scans and answers with a summary record; post a document and watch the claim, the lease and the result move through the Feed.

The console below starts at its sign-in screen: choose "Sign in as local operator". This space runs in open mode, and the console never assumes authority silently, so the operator session is a labeled button rather than a default, in the browser exactly as on a server.
