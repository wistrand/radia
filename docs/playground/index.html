What this is: the same runtime the server binary runs (storage, matching, leases, the full authorization stack, the event chain), booted in this tab with the actual console embedded above. The page seeds one claimable kind, document, and one toy worker that claims scans and answers with a summary record. The console starts at its sign-in screen because it never assumes authority silently: this space runs in open mode, so the operator session is a labeled button rather than a default, in the browser exactly as on a server.

Limits, stated rather than implied: no code execution (nothing in a page may spawn a process), one space per browser profile, and everything here runs as one person, so the console's operator button is the sign-in. Erasing the space is clearing this site's storage.
